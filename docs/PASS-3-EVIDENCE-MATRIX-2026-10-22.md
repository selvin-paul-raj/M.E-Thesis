# AVA Evaluation — Pass 3 evidence matrix (working, 22 October 2026)

## Decision at this checkpoint

The material reviewed so far does not support claiming that AVA is a novel four-class assertion-pair benchmark, a new conflict-preserving memory design, or the first use of abstention/verification for agent memory. MELD overlaps the four-way relation taxonomy and false-merge reporting, although its 104-pair diagnostic gold set deliberately uses distinct claim keys and therefore is not a strictly same-key pair test. Its status CRDT converges after partition heal, but its delivery-order-sensitive merge graph, live claim set, and retrieval view do not; AVA must state which semantic state it claims to reconcile. StateFuse and TOKI overlap conflict preservation, provenance/time-aware resolution, projection or write policies, deterministic decisions, and abstention/confirmation; LatticeMind and Memanto describe keyed or same-type memory conflict handling. TANGLE and Selective QA overlap conflict-aware action, calibration, and selective abstention. Governed Shared Memory directly studies asynchronous conflict supersession for same subject-predicate writes in a live multi-agent service, but not a pair classifier or AVA-style policy comparison. These threats make broad novelty claims unsafe; they do not prove exact preemption of the narrower AVA task.

A narrower candidate question is whether a deterministic evidence-based Verify stage, placed after classification of same-key assertions, changes the safety–resolution trade-off against fixed-winner selection and preserving every disagreement unresolved, under an asynchronous event simulator. This is only a candidate for continued falsification. It is not an admitted gap or a novelty finding. The required full-text Pass 3 is not complete; do not implement the protocol or draft the thesis/paper yet.

The supplied specification names WH-1, WH-2 and WH-3 but does not define them. Earlier repository prose that presented proposed wording as exact was agent-authored and is not authoritative; the corresponding wording has been removed from the active research-gap record. Do not infer or invent those definitions. Exact falsification against the three identifiers remains open until an authoritative definition is supplied. The matrix below still tests concrete AVA claims that the specification actually states. It records selected primary-source sections/excerpts reviewed, not source-wide, end-to-end reading. “Full text available” means a readable full-text version was obtained; it does not mean every section, appendix, or supplement was read. No source is marked fully verified at the project's level-P standard in this checkpoint.

## Resolved reference names

The project shorthand resolves to these exact sources, not a similarly named design: “Always-On Agents survey” = *Always-On Agents: A Survey of Persistent Memory, State, and Governance in LLM Agents* (arXiv:2606.30306v1); StateFuse = *StateFuse: Deterministic Conflict-Preserving Memory for Multi-Agent Systems* (arXiv:2607.05844v1); TOKI = *TOKI: A Bitemporal Operator Algebra for Contradiction Resolution in LLM-Agent Persistent Memory* (arXiv:2606.06240v1); S-Bus = *S-Bus: Automatic Read-Set Reconstruction for Multi-Agent LLM State Coordination* (arXiv:2605.17076v2); SCF = Acharya’s *Semantic Consensus: Process-Aware Conflict Detection and Resolution for Enterprise Multi-Agent LLM Systems* (arXiv:2604.16339v1; “Semantic Consensus Framework” is its proposed system); CodeCRDT = *CodeCRDT: Observation-Driven Coordination for Multi-Agent LLM Code Generation* (arXiv:2510.18893v1). The deterministic freshness reference cited in the spec has a revised v2 title: *Reliable Post-Retrieval Assembly for Agent Memory: Separating Evidence Extraction from Policy Execution* (arXiv:2606.01435v2).

## Quantitative-claim corrections

1. CodeCRDT’s ~5–10% is from manual review of 60 of 600 runs. The authors call the measure preliminary, report large task variation, and say comprehensive measurement is needed. Do not describe it as a validated persistent semantic-conflict rate.
2. SCF’s 65.2% is recall, not generic “detection” accuracy; 27.9% is precision. The paper reports F1 39.0 and states 72% of detections were false positives. Its 600-run simulated workflow task is not AVA’s same-key pair task.
3. The deterministic +10.8 to +21 points comes from a full candidate-extraction/Python-aggregation answer pipeline against an LLM-judgment pipeline on a serial-numbered freshness task. The paper says the comparison changes resolver, prompt, output format and temperature jointly; it does not isolate the resolver. The 262K abstract comparison is +21, while the HTML also reports +19.8 in a different matched chunk-4096 setup. The LongMemEval n=45 check does not show a deterministic win (57.8% versus 64.4%). Do not generalize to all semantic conflict resolution.
